## 🔗 Live Demo

## ✨ Features

- ⚡ Modern UI with gradient design
- 📱 Fully responsive (Mobile, Tablet, Desktop)
- 🎯 Smooth scroll & fade-in animations
- 🧠 Clear presentation of skills & projects
- 🔗 Integrated coding & professional profiles
- 💬 Interactive feedback form
- 🚀 Fast load time & optimized structure

## 🚀 Getting Started

To run locally:

```bash
git clone https://github.com/prathip2826/prathip-portfolio.git
cd prathip-portfolio
open index.html
```

No build tools or dependencies required — just open and go!
